Privacy & Local Data

Cat vs. Civilization is designed so you can play without creating an account or telling the site who you are.

The game does not ask for your name, email address, student ID, school records, or other personal information. It does not include advertising, analytics, forms, third-party scripts, or embedded services.

What the Game Saves

The game can save a small amount of information in your browser's localStorage so the map can remember completed encounters. The saved information is limited to completion markers, the last completed encounter, and the reduce-motion setting if you change it.

Your individual choices inside an encounter, temporary game meters, and moment-to-moment game state are not saved as a history.

Where That Information Goes

The locally saved game information stays in your browser. The game's own code does not send it to the site owner, a database, an analytics service, or an advertising service.

Erase Local Game Data

On the home screen, choose Options and then Erase under Local game data. That control removes only the game's own cvc-* save entries; it does not clear unrelated browser data.

On a shared computer, using this control when you are finished prevents the next person using the same browser profile from seeing which encounters were completed.

Hosting Information

The site may be hosted through GitHub Pages. Like other web hosts, the hosting provider may receive ordinary technical request information needed to deliver and protect the site, such as an IP address, browser information, and the pages requested. That provider-side logging is separate from the game's local save system.

Third-Party Requests

This version of the game does not load fonts, scripts, analytics, images, or embeds from third-party websites. Game assets are served from the same site as the game.
